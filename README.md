
# 🌱 Farm Guard

> An IoT-based smart agriculture system that monitors environmental
> conditions and provides real-time alerts using ESP32 and sensors.

## 🚀 Features

- 🌱 Real-time soil moisture monitoring
- 🌡️ Temperature and humidity monitoring
- 🔥 Flame detection
- 💨 Smoke/gas detection
- 📊 Real-time dashboard
- 🔔 Alert notifications
- 📡 IoT-based monitoring

## 🛠️ Technologies Used

- ESP32
- Arduino IDE
- C/C++
- DHT11
- Soil Moisture Sensor
- MQ-2 Gas Sensor
- Flame Sensor
- Blynk

## 🔌 Hardware Components

| Component | Purpose |
|---|---|
| ESP32 | Main controller |
| Soil Moisture Sensor | Measures soil moisture |
| DHT11 | Temperature & humidity |
| MQ-2 | Smoke/gas detection |
| Flame Sensor | Fire detection |
